# AZ-104: Azure Administrator

Outline effective: 2026-04-17. Checked: 2026-10-01. Target exam window:
December 2026–January 2027.

The certification concerns administering Azure infrastructure: identities,
governance, storage, compute, networks, monitoring, and recovery. Preparation
should combine conceptual decisions with configuration and troubleshooting.
Microsoft lists familiarity with operating systems, networking, servers, and
virtualization, plus experience with the Portal, CLI, PowerShell, Entra ID,
and ARM templates or Bicep. [Certification overview](https://learn.microsoft.com/en-us/credentials/certifications/azure-administrator/)

## Use this workspace

Start with [coverage](coverage.md) to identify available topics. Read the
implementation guidance, answer questions without the key, and review every
option explanation. Revisit missed concepts using a different scenario.

Use [Microsoft's training labs](https://github.com/MicrosoftLearning/AZ-104-MicrosoftAzureAdministrator)
for additional hands-on practice. Lab instructions can change as Azure changes;
check their prerequisites and cleanup steps before running them.

This repository currently contains a storage sample. Its scores measure only
those questions. It does not yet provide a balanced exam simulation or a
prediction of Microsoft's scaled exam score.
