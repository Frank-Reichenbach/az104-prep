# Azure Files

Available data-protection topics:

- [Share snapshots](snapshots.md): recover earlier file contents.
- [Share soft deletion](soft-delete.md): recover a deleted classic file share.

These address objective st-15. Provisioning shares and identity-based access
remain separate objectives awaiting detailed research. The examples use classic
shares under Microsoft.Storage; the specific topic states its SMB/NFS scope.

For the distinction between file shares and blob containers, return to the
[storage index](../index.md).
