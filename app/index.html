Test mode defaults to an exam-sized session: 50 questions in 100 minutes (2 minutes per question). Microsoft publishes no fixed length — typically 40–60 questions, 100 minutes, or 120 with labs (source). The session ends automatically when time runs out; unanswered questions are not scored.

How sessions are scored

  • Exact match. Select the stated number of answers; multiple-answer questions need every correct option and nothing else.
  • One variant per family. A session never shows two variants of the same question.
  • Mixed sessions balance questions across the exam domains. Short and review sessions can differ from the published proportions.
  • “Unsure” is recorded without a selection, does not count as correct, and can be reviewed later.
